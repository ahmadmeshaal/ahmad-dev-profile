# Setup

1. Create a **public** GitHub repository named exactly `ahmadmeshaal` under the `ahmadmeshaal` account.
2. Upload all files from this folder, including hidden `.github/workflows/profile-3d.yml`, preserving paths. Use `main` as the default branch.
3. Open **Settings → Actions → General → Workflow permissions** and select **Read and write permissions** if available. The workflow also declares `contents: write`.
4. Open **Actions → Generate 3D Contributions → Run workflow**. Wait for the first run and confirm that `profile-3d-contrib/profile-night-rainbow.svg` exists on `main`.
5. The profile README will display on your GitHub profile. Scheduled updates run daily; scheduled runs may be delayed by GitHub.

The header animation is self-contained SVG/CSS and requires no workflow. Some GitHub clients may disable animation or external stats cards. The featured Taqaddomi, perfume, and Laravel project cards intentionally omit unverified repository URLs.
